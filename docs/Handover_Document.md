안녕하세요! 내일 출근하셔서 이어서 작업하실 다음 에이전트(저)를 위한 인수인계서입니다. 😎

## 📌 현재까지의 프로젝트 요약 (Phase 1 완료)
- **개발 환경**: HTML, CSS, Vanilla JS 모듈 (`app.js`, `api.js`, `speech.js`, `prompts.js` 등)로 구성된 순수 프론트엔드 웹 애플리케이션입니다. 저장 데이터는 `localStorage`를 사용합니다.
- **주요 기능**: AI 기반 영작 교정, 번역, 단어장, 발음 평가, 일간 문장 추천, 유튜브 번역 등.
- **최근 완료 사항 (Phase 1)**: 
  - **단어장 맞춤 예문 기능**: 단어장에 사용자의 '관심사'를 입력하면, 해당 관심사에 맞춘 예문을 생성하여 저장해줍니다.
  - **뉘앙스 감별기 (Nuance Chatbot)**: 화면 우측 하단의 FAB 버튼(`💡 뉘앙스 질문`)을 누르면 모달 창이 뜨고, "see vs look" 처럼 헷갈리는 영어 단어의 차이를 Gemini AI가 완벽하게 분석해줍니다. (JS 로딩 지연/오류로 인한 버튼 무반응 이슈를 해결하기 위해 로직을 `app.js` 최상단으로 분리하고 HTML 인라인 이벤트를 추가하여 버그를 완벽하게 고쳤습니다).

### 1. 모바일 탭 메뉴 UI 수정 (가장 먼저 시작할 것!)

- `css/style.css` 하단의 `@media (max-width: 768px)` 미디어 쿼리를 수정하여 탭이 가로로 스크롤되도록(`flex-direction: row; overflow-x: auto; white-space: nowrap;`) 변경해야 합니다. 아이콘과 텍스트도 세로로 깨지지 않게 깔끔히 다듬어 주세요.

### 2. PDF 학습지 연동 (인터랙티브 쉐도잉 모드)
