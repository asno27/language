# 🚀 앞으로의 작업 기획서 (Future Implementation Plan)

본 문서는 앞으로 프로젝트에 추가하거나 개선할 '개발 예정 기능'들만 모아둔 기획서입니다. 기능 개발이 완료되면 본 문서에서 제외하고 `Completed_Features.md`로 이동합니다.

---

## 1. 🎭 AI 상황극 튜터 (Role-play) 
단순히 프리토킹을 넘어, 구체적인 목표가 있는 실전 회화 시뮬레이션을 제공하는 신규 탭입니다.

- **미션 기반 롤플레잉**: "스타벅스에서 커스텀 음료 주문하기", "공항 입국 심사 통과하기" 등 특정 상황을 설정하고 달성해야 할 미션을 부여합니다.
- **음성 대화**: 마이크(STT)를 이용해 내 목소리로 AI 원어민과 직접 대화하고, AI도 원어민 음성(TTS)으로 출력합니다.
- **종합 피드백**: 롤플레이가 종료되면, 내가 했던 문장들을 AI가 꼼꼼히 분석하여 '더 자연스러운 원어민 표현'이나 '문법 오류'를 교정해주는 리뷰 리포트를 제공합니다.

---

## 2. 💡 사용자 맞춤형 학습 데이터 대시보드
사용자의 영어 학습 패턴과 취약점을 분석하여 시각적인 데이터로 보여주는 기능입니다.

- 내가 가장 많이 틀리는 문법 유형 통계
- 단어장 암기율 및 주간 학습 달성도 차트 제공
