## 2. 💡 유튜브 자막 서버 Render 클라우드 배포 
현재 파이썬 로컬 서버(`localhost:8080`)에 의존하고 있는 유튜브 번역(자막 추출) 기능을 스마트폰 환경에서도 제약 없이 사용할 수 있도록 클라우드로 올립니다.

- **Render 활용**: 무료 클라우드 호스팅 서비스인 Render에 파이썬 백엔드 코드를 배포하여 프론트엔드와 연결합니다. (가장 쉽고 유지보수가 편리한 방식)

## 3. 🗣️ AI 상황극 튜터 (Role-play) 
단순한 프리토킹을 넘어, 구체적인 목표가 있는 실전 회화 시뮬레이션을 제공하는 신규 탭입니다.

- **미션 기반 롤플레잉**: "스타벅스에서 커스텀 음료 주문하기", "공항 입국 심사 통과하기" 등 특정 상황과 달성해야 할 미션을 부여합니다.
- **음성 대화**: 마이크(STT)를 이용해 내 목소리로 AI 원어민과 직접 대화하고, AI의 답변은 음성(TTS)으로 출력됩니다.
- **종합 피드백**: 롤플레이가 종료된 후, 내가 썼던 문장들을 AI가 꼼꼼히 분석하여 '더 자연스러운 원어민 표현'이나 '문법 오류'를 교정해주는 리뷰 리포트를 제공합니다.
