# 📝 앞으로의 작업 기획안 (Future Implementation Plan)

이 문서는 앞으로 프로젝트에 추가되거나 개선될 '개발 예정 기능'들만 모아둔 기획안입니다. 기능 개발이 완료되면 이 문서에서 삭제되고 `Completed_Features.md`로 이동됩니다.

---

## 1. 🖱️ 원클릭 미니 사전 & 즉시 단어장 추가 (최우선 진행)
웹사이트 내의 모든 영어 결과물(학습지, 유튜브 번역, 영작 교정 등)에서 모르는 단어를 만났을 때, 사전 탭으로 갈 필요 없이 직관적으로 뜻을 찾는 기능입니다.

- **원클릭 단어 선택**: 화면에 출력된 문장 속의 어떤 영어 단어든 클릭(모바일은 터치)할 수 있게 처리합니다.
- **미니 팝업 사전**: 단어를 클릭하면 그 자리에서 즉시 조그마한 말풍선이 떠오르며 단어의 뜻을 보여줍니다. (API 과부하 방지를 위해 마우스 Hover 대신 Click 방식 채택)
- **즉시 저장**: 말풍선 내에 `[+ 단어장에 추가]` 버튼을 배치하여, 한 번의 클릭으로 내 단어장 저장소에 직행하도록 만듭니다.

---

## 2. 💡 유튜브 자막 서버 Render 클라우드 배포 
현재 파이썬 로컬 서버(`localhost:8080`)에 의존하고 있는 유튜브 번역(자막 추출) 기능을 스마트폰 환경에서도 제약 없이 사용할 수 있도록 클라우드로 올립니다.

- **Render 활용**: 무료 클라우드 호스팅 서비스인 Render에 파이썬 백엔드 코드를 배포하여 프론트엔드와 연결합니다. (가장 쉽고 유지보수가 편리한 방식)

---

## 3. 🗣️ AI 상황극 튜터 (Role-play) 
단순한 프리토킹을 넘어, 구체적인 목표가 있는 실전 회화 시뮬레이션을 제공하는 신규 탭입니다.

- **미션 기반 롤플레잉**: "스타벅스에서 커스텀 음료 주문하기", "공항 입국 심사 통과하기" 등 특정 상황과 달성해야 할 미션을 부여합니다.
- **음성 대화**: 마이크(STT)를 이용해 내 목소리로 AI 원어민과 직접 대화하고, AI의 답변은 음성(TTS)으로 출력됩니다.
- **종합 피드백**: 롤플레이가 종료된 후, 내가 썼던 문장들을 AI가 꼼꼼히 분석하여 '더 자연스러운 원어민 표현'이나 '문법 오류'를 교정해주는 리뷰 리포트를 제공합니다.

---

## 4. 📖 인터랙티브 학습지 나머지 주차 (5~10주차) 연동
현재 1~4주차까지만 적용되어 있는 '일간소울영어 학습지' 데이터를 `worksheet.json`에 추가하여 10주차까지 모든 콘텐츠를 이용할 수 있도록 업데이트합니다.
