# Phase 2: 스피킹 & 실전 대화 마스터 (통합 기획안)

기존에 기획했던 **'AI 상황극 튜터'**와 방금 제안해드린 **'PDF 학습지 연동'**, 그리고 긴급히 요청하신 **'모바일 UI 개선'**을 하나로 완벽하게 통합한 2단계 기획안입니다. 

---

## 1. 📱 모바일 UI/UX 개선 (긴급 반영)
- **현재 문제**: 스마트폰 화면에서 상단 메뉴(네비게이션 탭)가 세로로 길게 쌓이면서(`flex-direction: column`) 화면 공간을 너무 많이 차지하고 아이콘만 보여 불편함.
- **해결 방안**: 
  - 모바일 환경에서 탭 메뉴를 **가로 스크롤(Horizontal Scroll)** 방식으로 변경.
  - 손가락으로 좌우로 부드럽게 스와이프하여 메뉴를 탐색할 수 있게 하고, 텍스트 라벨도 잘리거나 뭉개지지 않도록 반응형 CSS(`.nav-tabs`)를 수정.

---

## 2. 📖 인터랙티브 학습지 & 쉐도잉 훈련 (PDF 연동)
기존에 논의했던 '유튜브 쉐도잉 훈련 모드'를 사용자님의 **'일간소울영어 학습지'** 파일과 결합하여 막강한 기능으로 재탄생시킵니다.

- **주차별 콘텐츠 선택기**: 1~10주차까지 원하는 학습 주제(예: 오징어게임 토론, 대퇴사 시대 등) 선택.
- **빈칸 영작 퀴즈**: PDF에 있던 핵심 문장 빈칸 채우기를 웹에서 직접 타이핑하고 정답을 확인하는 인터랙티브 퀴즈로 구현.
- **써머리 낭독 & 발음 평가(쉐도잉)**: PDF 하단에 있던 요약본(Sample)을 보고, 마이크 버튼을 눌러 직접 낭독합니다. 기존의 발음 평가 AI 기능을 재활용하여 얼마나 자연스럽게 읽었는지 유창성을 평가받습니다.

---

## 3. 🗣️ AI 상황극 튜터 (Role-play)
단순한 프리토킹을 넘어, 구체적인 목표가 있는 실전 회화 시뮬레이션을 제공합니다.

- **미션 기반 롤플레잉**: "스타벅스에서 커스텀 음료 주문하기", "공항 입국 심사 통과하기" 등 특정 상황과 미션 부여.
- **대화 주고받기**: 마이크(STT)를 이용해 내 목소리로 AI와 직접 대화 (AI의 답변은 TTS로 들려줌).
- **종합 피드백**: 대화 미션이 종료된 후, 내가 썼던 문장들을 AI가 분석하여 '더 자연스러운 원어민 표현'으로 교정해주는 리뷰 리포트 제공.
