# Phase 2: 스피킹 & 실전 대화 마스터 (통합 기획안)

기존에 기획했던 **'AI 상황극 튜터'**와 방금 제안해드린 **'PDF 학습지 연동'**, 긴급히 요청하신 **'모바일 UI 개선'**, 그리고 새롭게 추가된 **'유튜브 번역 모바일 지원 (Render 백엔드 배포)'**을 하나로 완벽하게 통합한 2단계 기획안입니다. 

---

## 1. 📱 모바일 UI/UX 개선 (완료)
- **현재 문제**: 스마트폰 화면에서 상단 메뉴(네비게이션 탭)가 세로로 길게 쌓이면서 화면 공간을 너무 많이 차지하고 아이콘만 보여 불편함.
- **해결 방안**: 
  - 모바일 환경에서 탭 메뉴를 **가로 스크롤(Horizontal Scroll)** 방식으로 변경.
  - 텍스트 라벨이 보이도록 반응형 CSS(`.nav-tabs`, `.tab-btn`) 수정 완료.

---

## 2. 📖 인터랙티브 학습지 & 쉐도잉 훈련 (완료)
기존에 논의했던 '유튜브 쉐도잉 훈련 모드'를 사용자님의 **'일간소울영어 학습지'** 파일과 결합하여 막강한 기능으로 재탄생시켰습니다.

- **주차별 콘텐츠 선택기**: 1~10주차까지 원하는 학습 주제 선택. (현재 1~4주차 적용 완료)
- **빈칸 영작 퀴즈**: PDF에 있던 핵심 문장 빈칸 채우기를 웹에서 직접 타이핑하고 정답을 확인하는 인터랙티브 퀴즈로 구현.
- **써머리 낭독 & 발음 평가(쉐도잉)**: PDF 하단에 있던 요약본을 보고 마이크로 낭독하면, 기존 AI 엔진이 발음과 유창성을 채점.

---

## 3. 💡 모바일 지원을 위한 자막 서버 Render 배포 (진행 예정)
유튜브 번역 기능을 모바일(스마트폰) 환경에서도 제약 없이 사용할 수 있도록, 현재 로컬(`localhost`)에 의존하고 있는 파이썬 자막 서버를 **무료 클라우드 호스팅 서비스인 Render에 배포**합니다.

- **Render 채택 이유**: GitHub 저장소와 클릭 몇 번으로 쉽게 연동되며, 별도의 서버 관리 없이 코드가 수정될 때마다 자동 배포(CI/CD)를 지원하는 가장 직관적인 무료 플랫폼입니다.
- **구현 단계**:
  1. Render 서버 환경에 맞추어 `server/main.py`의 호스트 설정(Host/Port) 미세 조정.
  2. 서버 실행을 위한 구동 명령어 세팅(예: `Procfile` 또는 Render 설정 내 `Start Command` 지정).
  3. 프론트엔드(`api.js`)의 `YOUTUBE_API_URL`을 Render에서 발급받은 실제 클라우드 URL(예: `https://...onrender.com`)로 변경.

---

## 4. 🗣️ AI 상황극 튜터 (Role-play) (진행 예정)
단순한 프리토킹을 넘어, 구체적인 목표가 있는 실전 회화 시뮬레이션을 제공합니다.

- **미션 기반 롤플레잉**: "스타벅스에서 커스텀 음료 주문하기", "공항 입국 심사 통과하기" 등 특정 상황과 미션 부여.
- **대화 주고받기**: 마이크(STT)를 이용해 내 목소리로 AI와 직접 대화 (AI의 답변은 TTS로 들려줌).
- **종합 피드백**: 대화 미션이 종료된 후, 내가 썼던 문장들을 AI가 분석하여 '더 자연스러운 원어민 표현'으로 교정해주는 리뷰 리포트 제공.
