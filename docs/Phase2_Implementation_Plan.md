# Phase 2: 스피킹 & 실전 대화 마스터 (통합 기획안)

기존에 기획했던 **'AI 상황극 튜터'**와 방금 제안해드린 **'PDF 학습지 연동'**, 긴급히 요청하신 **'모바일 UI 개선'**, 그리고 새롭게 추가된 **'유튜브 번역 모바일 지원 대안'**을 하나로 완벽하게 통합한 2단계 기획안입니다. 

---

## 1. 📱 모바일 UI/UX 개선 (완료)
- **현재 문제**: 스마트폰 화면에서 상단 메뉴(네비게이션 탭)가 세로로 길게 쌓이면서 화면 공간을 너무 많이 차지하고 아이콘만 보여 불편함.
- **해결 방안**: 
  - 모바일 환경에서 탭 메뉴를 **가로 스크롤(Horizontal Scroll)** 방식으로 변경.
  - 텍스트 라벨이 보이도록 반응형 CSS(`.nav-tabs`, `.tab-btn`) 수정 완료.

---

## 2. 📖 인터랙티브 학습지 & 쉐도잉 훈련 (완료)
기존에 논의했던 '유튜브 쉐도잉 훈련 모드'를 사용자님의 **'일간소울영어 학습지'** 파일과 결합하여 막강한 기능으로 재탄생시켰습니다.

- **주차별 콘텐츠 선택기**: 1~10주차까지 원하는 학습 주제 선택. (현재 1~4주차 적용 완료)
- **빈칸 영작 퀴즈**: PDF에 있던 핵심 문장 빈칸 채우기를 웹에서 직접 타이핑하고 정답을 확인하는 인터랙티브 퀴즈로 구현.
- **써머리 낭독 & 발음 평가(쉐도잉)**: PDF 하단에 있던 요약본을 보고 마이크로 낭독하면, 기존 AI 엔진이 발음과 유창성을 채점.

---

## 3. 🗣️ AI 상황극 튜터 (Role-play) (예정)
단순한 프리토킹을 넘어, 구체적인 목표가 있는 실전 회화 시뮬레이션을 제공합니다.

- **미션 기반 롤플레잉**: "스타벅스에서 커스텀 음료 주문하기", "공항 입국 심사 통과하기" 등 특정 상황과 미션 부여.
- **대화 주고받기**: 마이크(STT)를 이용해 내 목소리로 AI와 직접 대화 (AI의 답변은 TTS로 들려줌).
- **종합 피드백**: 대화 미션이 종료된 후, 내가 썼던 문장들을 AI가 분석하여 '더 자연스러운 원어민 표현'으로 교정해주는 리뷰 리포트 제공.

---

## 4. 💡 모바일 환경에서 유튜브 번역 기능 활성화 방안 (추가)
현재 PC의 로컬 백엔드 서버(`localhost`)에 의존하고 있는 유튜브 자막 추출 기능을 모바일에서도 사용 가능하도록 만드는 대안들입니다.

### 대안 A: 무료 클라우드 서버 배포 (가장 추천)
현재 만들어진 파이썬 백엔드 코드(`server/main.py`)를 **Render**나 **PythonAnywhere** 같은 무료 클라우드 호스팅 서비스에 배포합니다.
- **장점**: 프론트엔드 코드(깃허브 페이지)를 수정할 필요 없이 API URL만 클라우드 주소로 바꾸면 끝납니다. 모바일에서도 언제나 접근 가능합니다.
- **단점**: 무료 서버 특성상 오랫동안 접속이 없다가 접속하면 서버가 깨어나는 데 10~20초 정도 걸릴 수 있습니다.

### 대안 B: Vercel 서버리스 플랫폼으로 이전
현재 GitHub Pages에서 서비스 중인 웹사이트 전체를 프론트/백엔드 통합 플랫폼인 **Vercel**로 이전합니다. 기존 파이썬 코드를 Vercel Serverless Function으로 변환하여 올립니다.
- **장점**: 프론트엔드와 백엔드가 완벽하게 통합되어 속도가 빠르고 CORS 보안 에러가 완벽히 사라집니다.
- **단점**: GitHub Pages 기반 배포에서 Vercel 기반 배포로 개발 환경을 조금 변경해야 합니다.

### 대안 C: 서드파티 외부 API 사용 (자체 서버 폐기)
파이썬 서버를 아예 쓰지 않고, RapidAPI 등에 이미 만들어져 있는 "유튜브 자막 추출용 상용 API(무료 티어)"를 가입하여 활용합니다.
- **장점**: 서버를 우리가 직접 관리할 필요가 없어집니다.
- **단점**: 무료 제공량이 제한적일 수 있으며, 외부 API에 의존하므로 서비스가 불안정해질 수 있습니다.

**결론 및 권장사항**: 가장 빠르고 코드를 덜 고쳐도 되는 **대안 A(무료 클라우드 서버 배포)**를 추천합니다. 원하신다면 제가 직접 클라우드에 올릴 수 있도록 세팅을 도와드릴 수 있습니다.
